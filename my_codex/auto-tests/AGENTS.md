# Internal repository AGENTS.md - Recomendations and Constraints

## Policy: "Zero-Review Code" (Код без ревью)
Ты работаешь как автономный CI-сервер. Ты НЕ имеешь права предлагать код на ревью человеку, пока не выполнишь следующие обязательные шаги:

1. **Сам себе Code Review**: После написания кода ты обязан запустить мысленный (или реальный, если есть линтер) анализ:
   - Соответствует ли код структуре фреймворка? (Проверь имена классов, импорты).
   - Нет ли `print()` или `sleep()`?
   - Нет ли голых `try/except` без логирования?
2. **Сам себе Тестировщик**: Ты должен сгенерировать фиктивные входные данные и «прогнать» свой же код мысленно (dry-run), убедившись, что не будет `IndexError` или `KeyError`.
3. **Формат сдачи**: Ты предоставляешь мне **не код**, а **отчет о выполненной работе** в формате:
   - `Задача: TASK-001`
   - `Написано тестов: 5 шт.`
   - `Использованы методы фреймворка: api_client.post, wait_for_element`
   - `Ссылки на файлы в auto-tests/: [пути к файлам]`
   - `Результат мысленного прогона: Успешно (все ассерты пройдут)`
4. **Исключение**: Если ты не уверен в каком-то аспекте (например, правильно ли обрабатывается конкретный статус-код), ты **не додумываешь**, а помечаешь это в `TASK_MEMORY.md` как `[NEED_CLARIFICATION]` и пропускаешь этот тест, но код для остальных тестов всё равно сдаешь.
