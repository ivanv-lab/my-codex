# Инструкции для AI-агентов

Это репозиторий с указанием процесса тестирования и автоматизации тест-кейсов.

Каждая отдельная задача и ее контекст будут располагаться в директории `tasks`.

## Структура

- `msg-claude` - функциональный репозиторий, содержит основное описание и возможности агента;
- `msg-docs` - ключевая директория для составления тест-кейсов - содежит информацию о функционале и бизнес-фичах всевозможных функций системы. Идельно работает вместе с `Wiki Confluence`;
- `msg-tests` - репозиторий для автоматизации тестирования. Этот репозиторий содержит собственный `AGENTS.md` для описания своих ключевых функциой, возможностей и ограничений;
- `msg-issues` - пробный репозиторий для клиентских задач. Иногда там можно найти информацию по тестируемой задаче;
- `.env` - файл с кредами доступов;
- `tasks` - директория, включающая в себя задачи для контроля контекста выполнения и ведения для каждой задачи своего собственного контекста;
- `skills` - директория, содержащая общие скиллы с подробной пошаговой инструкцией для каждой;
- `util-files` - содержит утилитарные файлы, которые могут пригодиться для множества задач. Например, файл о свойствах эмуляторов, будет находиться там
- `MEMORY.md` - файл для записи основных положений о работе, средах, информации о системе.

## Стиль работы

- Перед началом работы в сессии - перечитай MEMORY;
- Действовать самостоятельно и минимизировать interruptions;
- Спрашивать перед действиями: `build`, `commit`, `push`, удаление `.md`-файлов;
- После рефакторинга обновлять документацию: `AGENTS.MD`;
- При изменениях в любом репозитории вести краткую документацию в корневом `CHANGES.md`; особенно фиксировать изменения в `msg-tests`, так как это ключевой репозиторий прямой автоматизации и частых правок;
- Использовать креды с доступами из файла ~/projects/ivozisov/.env;
- При работе с определенным репозиторием или `tasks`, прочитать вложенный `AGENTS.md`.

## Глобальные ограничения

- `build`, `commit`, `push` запрещены для всех репозиториев и файлов, кроме `msg-tests`.
